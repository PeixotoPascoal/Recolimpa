# RECOLIMPA — site institucional

Site responsivo de página única, em português, preparado para apresentar os serviços da RECOLIMPA e receber pedidos de proposta.

## Publicação e recolha de pedidos

O formulário está preparado para os formulários do Netlify. Para receber os pedidos:

1. Publique a pasta recolimpa-site no Netlify.
2. Confirme que a detecção de formulários está activa nas definições do site e publique novamente, se necessário.
3. Os pedidos enviados ficam disponíveis na área Forms do painel do site.

O formulário inclui nome, telefone, organização, local, serviço pretendido, detalhes e consentimento para contacto. A página obrigado.html é apresentada após o envio.

O site não apresenta número de telefone ou endereço de e-mail porque esses contactos não foram fornecidos.
